# ozone-flow-digital-twin
Имитационная модель и цифровой двойник сортировочного центра (100 000 товаров/час). Автоматизация, 3D-визуализация, аналитика узких мест и what-if сценарии. Оптимизация потоков КТЯ и ворот отгрузки. Построено на SimPy, Streamlit и Blender.








#  Ozone Flow Digital Twin

**Имитационная модель и цифровой двойник сортировочного центра (СЦ)**

>  **Аналогия из биологии:** Представь сортировочный центр как кровеносную систему крупного организма. Конвейеры — это вены, товары (КТЯ) — эритроциты, а сортировщик — сердце, которое качает их по нужным артериям (направлениям). Наша модель — это симулятор этой системы, позволяющий проверить, не случится ли "инфаркт" (затор) при пиковых нагрузках.

##  О проекте

Данный репозиторий содержит полноценную имитационную модель сортировочного центра, обрабатывающего до **100 000 товаров в час** по **400 направлениям**. 
Решение позволяет оценить работоспособность схемы, найти узкие места (бутылочные горлышки), рассчитать требуемую площадь и сравнить уровень автоматизации с ручным трудом.

**Цифровой двойник** (виртуальная копия, повторяющая поведение реального объекта) построен с использованием дискретно-событийного моделирования.

##  Стек технологий

*   **Python 3.12** — основной язык.
*   **SimPy** — библиотека для дискретно-событийного моделирования (процессы идут скачками во времени, а не плавно).
*   **Streamlit** — фреймворк для быстрого создания веб-интерфейсов (дашбордов) на Python без знания HTML/CSS/JS.
*   **Pandas / NumPy** — обработка данных и аналитика.
*   **Plotly / Matplotlib** — построение интерактивных графиков.
*   **Docker** — система контейнеризации (упаковывает код и все зависимости в один "контейнер", чтобы он запускался везде одинаково).
*   **Blender / Three.js** *(опционально)* — для 3D-визуализации потоков.

##  Быстрый старт (Как запустить)

### Вариант 1: Через Docker (Рекомендуется)

```bash
# Собрать образ
make build

# или вручную: docker run -v ./data:/app/data ozone-sim python -m src.run --hours 24
